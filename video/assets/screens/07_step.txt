M4 GiveMeSomeCredit terra

stats::glm in R, migrated to Python with statsmodels.api.GLM (exact parity tier); the data scientist accepted the migration.

File	
model.py	The model: prepare, fit and predict
report.md, plots/	Model validation report and its plots
validation.json	The accepted parity checks against the R reference, with the model validation checks and business fitness verdict
spec.json	The confirmed model specification, v1
baseline.R	The R code the reference ran
reference/	The R reference results: coefficients, predictions, R's train and test rows, subgroup values, fit statistics, design summary
environment/	pyproject.toml and uv.lock for Python, renv.lock for R
verify.py, parity.py, harness.py, verify.json	Rerun and compare with R
manifest.json	SHA-256 of every file
Rerun
uv sync --frozen --project environment
uv run --frozen --project environment python verify.py path/to/cs-training.csv


cs-test.csv must be in the same directory as the dataset.

verify.py checks the SHA-256 of every data file, fits model.py on R's train rows, predicts on every set R formed and repeats the parity checks against reference/: convergence, coefficient names, estimates and standard errors, alignment keys, observed values, prediction missingness and values, fit statistics and the requested evaluation metrics, each as |Python − R| ≤ atol + rtol·|R| with the spec's tolerances. Checks that were unavailable or excluded at acceptance are listed in the output.

The R baseline used R 4.6.2 (2026-10-29) with the packages in environment/renv.lock (renv::restore(lockfile = "environment/renv.lock")).
